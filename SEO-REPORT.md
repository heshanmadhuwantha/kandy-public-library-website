# SEO Report — Kandy Public Library Website

**Project:** NIBM CW01 Coursework  
**Scenario:** Kandy Public Library — Public-Facing Community Library Website

## 1. Website Overview

The Kandy Public Library website is a multi-page public-facing web application developed for the NIBM CW01 coursework scenario. The front end uses HTML, CSS and JavaScript, while PHP and MySQL are used for the required database interaction. The website provides information about the library, its book catalogue and services, and allows public users to submit membership and contact information.

The SEO approach focuses on making each public page understandable to both users and search engines through relevant keywords, unique page titles, meta descriptions, semantic HTML, a logical heading hierarchy and descriptive image alternative text.

## 2. Target Audience and Search Intent

The website is intended for:

- **Students** searching for books, study resources and library services.
- **General readers and families** looking for books, membership information and community library facilities.
- **Researchers and other public users** looking for reference material, services and contact information.

These users may search using the library name, location-based phrases or task-based queries such as finding books, viewing services or applying for membership.

## 3. Keyword Strategy

The keyword strategy uses terms that directly describe the chosen scenario and the content available on the website.

**Primary and supporting keywords include:**

- Kandy Public Library
- public library Kandy
- book catalogue Kandy
- library books
- borrow books Kandy
- library services Kandy
- library membership Kandy
- apply for library membership
- Kandy Public Library contact
- library opening hours

Keywords are selected according to the topic and purpose of each page rather than repeating the same phrase excessively across the entire website.

## 4. Page-by-Page Keyword Mapping

| Page | Main Target | Supporting Terms | User Intent |
|---|---|---|---|
| Home | Kandy Public Library | public library Kandy, community library | Find and understand the library |
| About | About Kandy Public Library | library mission, community library | Learn about the organization |
| Books | book catalogue Kandy | library books, search books | Find available books |
| Services | library services Kandy | book lending, reading facilities | Learn about services |
| Membership | library membership Kandy | apply for membership, join library | Apply or obtain membership information |
| Contact | Kandy Public Library contact | address, phone, email, opening hours | Contact or locate the library |

This mapping gives each page a clear topic and reduces unnecessary competition between pages for the same general keyword.

## 5. Page Titles and Meta Descriptions

Each main public page uses a unique and descriptive `<title>` element:

| Page | Page Title |
|---|---|
| Home | Kandy Public Library \| Home |
| About | Kandy Public Library \| About Us |
| Books | Kandy Public Library \| Books |
| Services | Kandy Public Library \| Library Services |
| Membership | Kandy Public Library \| Membership |
| Contact | Kandy Public Library \| Contact Us |

The meta descriptions are also page-specific. For example, the Books page describes the book catalogue and its search/filter functionality, while the Membership page explains that users can apply through an online form. This helps communicate the purpose of each page in search-result snippets.

## 6. Keyword Placement Strategy

Relevant keywords are placed naturally in appropriate on-page locations, including:

- the page `<title>`
- the meta description
- the main `<h1>` heading
- relevant `<h2>` and `<h3>` headings
- introductory and descriptive page content
- descriptive internal link text

Keywords are not inserted repeatedly simply to increase their frequency. The content is written primarily for visitors, while ensuring that page topics remain clear to search engines.

## 7. Semantic HTML and Heading Structure

The website uses semantic HTML5 elements to provide a clear structure for page content. The main elements include:

- `<header>` for site branding and the top section
- `<nav>` for primary navigation
- `<main>` for the unique content of each page
- `<section>` for major content areas
- `<article>` for self-contained content such as cards where appropriate
- `<footer>` for shared footer information

Each page has one main `<h1>` describing its primary topic. Major sections use `<h2>` headings, while lower-level content and repeated items use `<h3>` headings where appropriate.

Examples of main page topics include:

- Home: **Kandy Public Library**
- Books: **Our Book Catalogue**
- Services: **Library Services**
- Membership: **Become a Member**
- Contact: **Contact Us**

This structure helps users and search engines understand the relationship between the main topic and supporting content.

## 8. Image Alternative Text

Meaningful images use descriptive `alt` attributes so that their purpose or content is available when an image cannot be viewed and can be interpreted by assistive technologies. Decorative icons are treated as decorative where appropriate rather than being given unnecessary descriptive text.

## 9. Internal Linking and Crawlability

The shared navigation and footer provide links between the main public pages. Contextual links are also used where relevant, such as directing users from the Home or Services pages to books or membership information.

Descriptive anchor text is used instead of vague wording such as “click here”. This improves navigation for users and provides clearer context about linked pages. Standard HTML links also help crawlers discover the main public sections of the website.

## 10. robots.txt and sitemap.xml

The project includes a `robots.txt` file to define crawler access and identify the sitemap. It also includes a `sitemap.xml` containing the major public pages:

- Home
- About
- Books
- Services
- Membership
- Contact

Before the website is published, the placeholder `.example` address used in the current project files must be replaced with the final deployed website URL. The same final URL must be used consistently in both `robots.txt` and every `<loc>` entry in `sitemap.xml`.

## 11. Responsive Design and Mobile Usability

The website is designed to work on desktop and mobile screen sizes. Responsive CSS layouts and a mobile navigation menu are used to keep the content readable and usable across different devices. This supports a consistent experience for visitors accessing the public website from mobile devices.

## 12. Overall SEO Strategy Summary

The on-page SEO implementation focuses on the coursework requirements and includes:

- Unique page titles
- Page-specific meta descriptions
- Relevant keyword targeting
- Keyword-to-page mapping
- Semantic HTML5 structure
- A logical H1, H2 and H3 hierarchy
- Descriptive image `alt` attributes
- Internal linking with descriptive anchor text
- `robots.txt` and `sitemap.xml`
- Responsive and mobile-friendly page layouts

The strategy does not claim guaranteed search rankings. Its purpose is to help search engines understand the website's pages and content while providing clear, relevant information to public users.
